cl_quick's menu: showing which accounts a profile holds

A profile is a Claude Code folder, such as Claude Main or Claude Work. It holds one or more accounts: one is in use, the others stand by. Signing in again in the same folder switches to a standby account. The menu today does not show that structure. Below it, three ways to draw it, each with one profile and with two. Sample names and addresses throughout. Nothing is built.

  1. Drawn like macOS: dark menu, the system font, the native blue highlight, shown at twice the real size.
  2. Addresses are blurred until the pointer is on their row, as today. Point at any row on this page to see its hover.
  3. Always in the menu: Quick chat with its shortcut at the top, then the profiles, then Settings… and Quit.
  4. No usage numbers yet shows on Claude Work, so you see that state too. Only the account in use ever shows numbers.
