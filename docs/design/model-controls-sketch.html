cl_quick: model and thinking controls, four ideas

Build 103's step controls failed: the model showed one bar, and a click on a half changed the label's width so the control slid out from under the pointer. These are four ideas for the two controls, each live in the real row (● Main · model · thinking · Send) at 320 and 440 pt. Click, hover and scroll them. Sample models; the list switch below gives an account four, three or two families.

  • Nothing moves under the pointer: every control is as wide for every value it can take.
  • The current value reads at a glance, and one click (or one drag) reaches any value.
  • 2–4 models and 2–6 thinking levels; a level the model doesn't take stays in its place, faint.
  • The cost tint for Fable and for Extra and Max; stronger when both. Fits 320 pt. Scroll over a control steps it in every idea; ⌥⌘ arrows stay.
RESEARCH

Why build 103 showed one model bar

Claude Code names the models by family alone on this account, with the version only in the description, and the parser wanted the version in the name. It found none of the four families, and the control fell back to a single step: the family in use, one bar. Reproduced from the list Claude Code gave the Main profile (cl_quick's own copy of it), through main's engine: 
value "opus"                  displayName "Opus"    description "Opus 5.5 · Best for everyday, complex tasks"
value "claude-fable-5-1[1m]"  displayName "Fable"   description "Fable 5.1 · Most capable for …"
value "sonnet" / "haiku"      displayName "Sonnet" / "Haiku", versions in their descriptions
main's parser:  families found []   → the model control's fallback: one step
reading the description too:  haiku, sonnet, opus, fable  (Fable 5.1, the others 5.5)
The fix is small (take the family from the name and the version from the description) and is not part of this sketch. It is already on the stopped branch feat/steps (commit 6623f98), unmerged.
TRY THEM

The list

Applies to all four ideas.

Account has Haiku takes Off to High, Sonnet Off to Extra, Opus and Fable Off to Max.
IDEA A

Bars you pick directly

A label sized for the longest value, then a 10 pt column per step. Off is a dash.

Why it works: every value is one click on its own bar; the rising bars say "more" without words, and the label says exactly what's in use (hover previews a bar's name in the same place, so nothing moves). Fast to step, compact. What it costs: 10 pt targets are small for a trackpad; a gap shows after short labels ("Max ▂▄▆") because the label keeps the longest value's width. At 320 the labels shorten to the family ("Sonnet").

IDEA B

Two small segmented controls

Every choice visible as a letter: H S O F, and – L M H X M+.

Why it works: it reads like a macOS segmented control: all choices on view, the chosen one raised, one click anywhere. Targets are 19–24 pt wide, twice A's. Hover names the segment above it. What it costs: letters must be learned (M is Medium, M+ is Max; S is Sonnet); at 320 there's no room for a label, so the full name is only on hover. At 440 a label sits before each, and the profile key keeps only its dot to make room.

IDEA C

One chip, a popover with big rows

"Opus 5.5 · High", fixed width. Press, and both lists open side by side.

Why it works: the row stays calm and fully readable; the popover has 30 pt rows with words, Claude Code's description under each model, and the cost said in words. Press-drag-release picks in one gesture; a click opens it and a second click picks. Scroll over the chip steps thinking (⇧ scroll steps the model). What it costs: it's a menu again (two clicks for the casual user, which the operator asked to get away from) and a small custom window to build.

IDEA D

One "power" slider

Model and thinking together, on one scale from light to heavy.

Why it works: one question instead of two ("how hard should it try?"), one drag or one click on a stop; the scale itself warms towards the costly end. What it costs: it picks from a set of pairs, not any pair (no Haiku with High, no Opus with Off); the pairs have to be chosen and kept as models change, and the stops sit close together (about 10 pt).
