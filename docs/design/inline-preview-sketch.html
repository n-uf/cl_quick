cl_quick: a page shown in place

An html code block in an answer shows its finished page right inside the block. Five states at the panel's real size (520 × 580 pt) in the app's look, plus a light variant of the first. Sample content only. Nothing is built.

PROPOSED

  • Page is the default for a finished html block. The header keeps its place above the page: html on the left; on the right a small two-way switch Code | Page (the chosen side raised), ⤢ (open in a big window) and copy.
  • The model decides. A block fenced as ```html code opens as code, with the switch on Code. A plain ```html block opens as a page.
  • Tall pages are capped at about half the panel and scroll inside their block.
  • A page that scrolled out of view comes back as a still picture, marked with a small muted still tag in the header (state 4 explains why that mark).
  • While the block streams it is code with no switch; the page appears when the block is complete.
